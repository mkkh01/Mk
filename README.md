# 🤖 نظام المؤشرات الثلاثة — تداول ورقي (30 زوجاً)

نظام آلي يطبق استراتيجية **EMA 200 + Stochastic + Fibonacci** على 30 عملة رقمية
بخط أنابيب 3 فريمات (**1h سياق ← 15m إعداد ← 5m إشعال**)، يعمل بدورة كل دقيقة،
ويُدار بالكامل من بوت تلجرام بالعربية.

> تداول ورقي (بدون أموال حقيقية وبدون رافعة) لكنه يحاكي الحقيقي: رسوم، انزلاق،
> وقف/هدف، إشعار فوري لكل صفقة، ومتابعة حتى الإغلاق مع سبب النتيجة.

---

## 1. كيف يعمل؟ (3 طبقات)

```
[عند الإقلاع] جلب تاريخي: 260 شمعة × 30 رمز × 3 فريمات → كاش Redis
        ↓
[كل دقيقة] الدورة الرئيسية: تحديث خفيف للشموع → المؤشرات → إشارات جديدة
        → فحص الإشارة المعاكسة → فتح صفقات → Summary Cycle
        ↓
[لحظياً] بث WebSocket للأسعار (تيك فوري) + مراقب سريع كل 5 ثوانٍ:
        ضرب الوقف/الهدف → إغلاق فوري + إشعار تلجرام خلال ثوانٍ ⚡
```

> العمل يبدأ دائماً من **آخر شمعة مغلقة + السعر الحي**:
> الشمعة الحية (غير المكتملة) تُستبعد من حساب المؤشرات لاستقرار الإشارة،
> بينما الدخول والوقف/الهدف بسعر السوق اللحظي.

## 2. الاستراتيجية: المؤشرات الثلاثة (3 فريمات)

```
[1h سياق]  السعر فوق/تحت EMA200 + الميل يدعم الاتجاه
     ↓
[15m إعداد]  Swing مؤكد (pivots مؤكدة) ← منطقة فيبو 50–61.8 (+العميقة)
     + التقاء: مستوى أفقي / EMA200 / تفاعلات سابقة
     ↓
[5m إشعال]  تشبع ستوكاستيك + تقاطع حديث + شمعة تأكيد
     (ابتلاع / رفض / مطرقة-شهاب / كسر زناد / إغلاق عائد)
     ↓
[فلاتر صلبة]  10 شروط إلزامية + فلتر تقلب (ATR/Close بين 0.3% و8%)
     ↓
[النقاط 0-100]  ترند 25 + فيبو 25 + ستوكاستيك 20 + تأكيد 20 + منطقة 10
     ≥70 اعتماد ✅ | 60–69 مراقبة 👀 | أقل رفض ❌
```

| الدرجة | المعنى |
|---|---|
| 90+ 🏆 | PREMIUM — إعداد مثالي |
| 80+ 💪 | HIGH QUALITY — عالية الجودة |
| 70+ ✅ | VALID SETUP — صالحة للتداول |
| 60–69 👀 | WATCH — تحت المراقبة (تُسجل ولا تُتداول) |

**الوضع الثابت (النشط):** كل صفقة بقيمة **30$**، والخروج عند **صافي ربح ~0.22$** (بين 0.20 و0.25$) بعد الرسوم والانزلاق — والوقف يبقى هيكلياً (خلف القاع/القمة + `ATR×0.2`).
لوضع المواصفة الأصلي (1% مخاطرة + هدف هيكلي + حد 1:1.3): ضع `FIXED_NOTIONAL_USDT=0` و`FIXED_TP_NET_USDT=0`.
**التنفيذ:** انزلاق 5 نقاط أساس + رسوم سبوت 0.1% لكل جهة.
**المخاطرة:** 1% لكل صفقة، حد أقصى **3 صفقات** و3% مخاطرة محفظة، بدون رافعة (1x)،
تبريد 30 دقيقة لكل رمز، ومنع الإشارات المكررة.

> **لماذا 3 فريمات؟** الفريم الكبير يمنع صفقات عكس السوق، والمتوسط يبني الإعداد،
> والصغير يوقّت الدخول — والإشارات تُبنى على شموع **مغلقة** فقط (لا إعادة رسم).

## 2-مكرر. الباك-تست والاختبار الذاتي

```bash
python -m app.selftest                 # فحص سريع: سيناريو LONG/SHORT + فلاتر + نقاط
python -m app.backtest BTCUSDT --days 60   # اختبار تاريخي بنفس محرك القرار الحي
python -m app.backtest BTCUSDT --days 90 --walk 3  # نوافذ Walk-Forward (3×30 يوم)
python -m app.backtest BTCUSDT --days 60 --min-score 75 --rr-min 1.5  # تجاوز بارامترات
```

## 6. النشر على Render (خطوة بخطوة)

### أ) قاعدة البيانات (طريقتان)
**الطريقة 1 - رابط Postgres المباشر (الأسهل، موصى به):**
1. من Supabase ← Project Settings ← Database ← انسخ **Connection string** (وضع Pooler)
2. ضعه في `SUPABASE_URL` — النظام **ينشئ الجداول الثمانية تلقائياً** عند أول تشغيل ✅
3. `SUPABASE_KEY` غير لازم في هذه الطريقة

**الطريقة 2 - Supabase API:**
1. من SQL Editor نفّذ محتوى ملف `supabase_schema.sql` (ينشئ الجداول يدوياً)
2. من Project Settings ← API انسخ `Project URL` و `service_role key`

### ب) Redis (الكاش)
- الأسهل والمجاني: Upstash (upstash.com) ← Create Redis ← انسخ `REDIS_URL` (يبدأ بـ `rediss://`)
- أو Redis مدفوع من Render نفسها.

### ج) بوت التلجرام
1. من `@BotFather`: أنشئ بوتاً وانسخ التوكن
2. من `@userinfobot`: انسخ رقم الشات `Chat ID`
3. أرسل أي رسالة للبوت الجديد (ضروري ليستطيع مراسلتك)

### د) رفع الكود
```bash
git init && git add . && git commit -m "trading bot"
# أنشئ مستودعاً على GitHub ثم:
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
```

### هـ) النشر
1. Render Dashboard ← New ← **Blueprint** ← اختر المستودع (يقرأ `render.yaml`)
2. املأ متغيرات البيئة (الجدول تحت) ← Deploy
3. بعد الإقلاع انسخ رابط الخدمة (مثل `https://xxx.onrender.com`)
4. أضف متغير `WEBHOOK_BASE_URL` = الرابط بدون `/` في النهاية ← Save (يُعاد التشغيل تلقائياً)
5. افتح التلجرام ← `/start` ← ستعمل الأزرار ✅

### و) متغيرات البيئة المطلوبة على Render

| المتغير | من أين | إجباري؟ |
|---|---|---|
| `SUPABASE_URL` | Supabase ← Settings ← API | ✅ نعم |
| `SUPABASE_KEY` | Supabase ← service_role key | ✅ نعم |
| `REDIS_URL` | Upstash أو Render Redis | مستحسن جداً |
| `TELEGRAM_BOT_TOKEN` | BotFather | ✅ نعم |
| `TELEGRAM_CHAT_ID` | userinfobot | ✅ نعم |
| `WEBHOOK_BASE_URL` | رابط خدمتك على Render | ✅ نعم (بعد أول نشر) |
| `WEBHOOK_SECRET` | يُولَّد تلقائياً من render.yaml | تلقائي |

> بدون Supabase/Redis يعمل النظام بتخزين محلي مؤقت (يُفقد عند إعادة التشغيل) -
> مناسب للتجربة فقط.

### ز) ضبط اختياري (له قيم افتراضية)

`CYCLE_SECONDS=60` `MONITOR_SECONDS=5` `WS_ENABLE=1`
`RISK_PCT=1.0` `MAX_OPEN_TRADES=6`
`RR_MIN=1.3` `FEE_PCT=0.1` `MAX_HOLD_HOURS=48` `START_BALANCE=10000`
