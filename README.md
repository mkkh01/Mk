# 🤖 نظام التداول الورقي بدون رافعة (30 زوجاً)

نظام آلي يطبق استراتيجية **EMA 200 + Stochastic + Fibonacci** على 30 عملة رقمية،
يعمل بدورة كل دقيقة، ويُدار بالكامل من بوت تلجرام بالعربية.

> تداول ورقي (بدون أموال حقيقية وبدون رافعة) لكنه يحاكي الحقيقي: رسوم، وقف/هدف،
> إشعار فوري لكل صفقة، ومتابعة حتى الإغلاق مع سبب النتيجة.

---

## 1. كيف يعمل؟ (3 طبقات)

```
[عند الإقلاع] جلب تاريخي: 260 شمعة × 30 رمز × فريمين → كاش Redis
        ↓
[كل دقيقة] الدورة الرئيسية: تحديث خفيف للشموع → المؤشرات → إشارات جديدة
        → فحص الإشارة المعاكسة → فتح صفقات → Summary Cycle
        ↓
[لحظياً] بث WebSocket للأسعار (تيك فوري) + مراقب سريع كل 5 ثوانٍ:
        ضرب الوقف/الهدف → إغلاق فوري + إشعار تلجرام خلال ثوانٍ ⚡
```

> العمل يبدأ دائماً من **آخر شمعة مغلقة + السعر الحي**:
> الشمعة الحية (غير المكتملة) تُستبعد من حساب المؤشرات لاستقرار الإشارة،
> بينما الدخول والوقف/الهدف بسعر السوق اللحظي.

## 2. الاستراتيجية (من ملف الدليل)

| المحرك | الدور | الشرط |
|---|---|---|
| **EMA 200 على 1h** | فلتر الترند الكبير | السعر فوقه = شراء فقط، تحته = بيع فقط |
| **EMA 200 على 15m** | تأكيد الترند | نفس الشرط على فريم الدخول |
| **فيبوناتشي 15m** | منطقة الدخول | السعر في منطقة الخصم 50%–61.8% (±سماحية) |
| **ستوكاستيك 15m** | التوقيت | تحت 20 للشراء / فوق 80 للبيع (+التقاطع أقوى) |
| **شمعة انعكاسية** | تأكيد إضافي | ابتلاع / مطرقة / شهاب (يقوّي الإشارة) |

**القاعدة العليا:** لا دخول إلا بالتقاء الترند + المنطقة + التوقيت (3/5 على الأقل).
**الوقف:** تحت القاع/فوق القمة + هامش ATR | **الهدف:** القمة/القاع السابق بحد أدنى 1:2.
**المخاطرة:** 1% من المحفظة لكل صفقة، بدون رافعة (1x)، حد أقصى 6 صفقات، رسوم سبوت 0.1% لكل جهة.

> **لماذا فريمان؟** سؤالك كان: فريم واحد أم عدة؟ اخترت **1h للترند + 15m للدخول**:
> الترند الكبير يمنع صفقات عكس السوق، وفريم 15m يعطي فرصاً كافية لدورة كل دقيقة
> (الدورة كل دقيقة للمراقبة اللحظية للوقف/الهدف، والإشارات تُبنى على شموع 15m المغلقة).

## 6. النشر على Render (خطوة بخطوة)

### أ) قاعدة البيانات (طريقتان)
**الطريقة 1 - رابط Postgres المباشر (الأسهل، موصى به):**
1. من Supabase ← Project Settings ← Database ← انسخ **Connection string** (وضع Pooler)
2. ضعه في `SUPABASE_URL` — النظام **ينشئ الجداول الخمسة تلقائياً** عند أول تشغيل ✅
3. `SUPABASE_KEY` غير لازم في هذه الطريقة

**الطريقة 2 - Supabase API:**
1. من SQL Editor نفّذ محتوى ملف `supabase_schema.sql` (ينشئ الجداول يدوياً)
2. من Project Settings ← API انسخ `Project URL` و `service_role key`

### ب) Redis (الكاش)
- الأسهل والمجاني: Upstash (upstash.com) ← Create Redis ← انسخ `REDIS_URL` (يبدأ بـ `rediss://`)
- أو Redis مدفوع من Render نفسها.

### ج) بوت التلجرام
1. من `@BotFather`: أنشئ بوتاً وانسخ التوكن
2. من `@userinfobot`: انسخ رقم الشات `Chat ID`
3. أرسل أي رسالة للبوت الجديد (ضروري ليستطيع مراسلتك)

### د) رفع الكود
```bash
git init && git add . && git commit -m "trading bot"
# أنشئ مستودعاً على GitHub ثم:
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
```

### هـ) النشر
1. Render Dashboard ← New ← **Blueprint** ← اختر المستودع (يقرأ `render.yaml`)
2. املأ متغيرات البيئة (الجدول تحت) ← Deploy
3. بعد الإقلاع انسخ رابط الخدمة (مثل `https://xxx.onrender.com`)
4. أضف متغير `WEBHOOK_BASE_URL` = الرابط بدون `/` في النهاية ← Save (يُعاد التشغيل تلقائياً)
5. افتح التلجرام ← `/start` ← ستعمل الأزرار ✅

### و) متغيرات البيئة المطلوبة على Render

| المتغير | من أين | إجباري؟ |
|---|---|---|
| `SUPABASE_URL` | Supabase ← Settings ← API | ✅ نعم |
| `SUPABASE_KEY` | Supabase ← service_role key | ✅ نعم |
| `REDIS_URL` | Upstash أو Render Redis | مستحسن جداً |
| `TELEGRAM_BOT_TOKEN` | BotFather | ✅ نعم |
| `TELEGRAM_CHAT_ID` | userinfobot | ✅ نعم |
| `WEBHOOK_BASE_URL` | رابط خدمتك على Render | ✅ نعم (بعد أول نشر) |
| `WEBHOOK_SECRET` | يُولَّد تلقائياً من render.yaml | تلقائي |

> بدون Supabase/Redis يعمل النظام بتخزين محلي مؤقت (يُفقد عند إعادة التشغيل) -
> مناسب للتجربة فقط.

### ز) ضبط اختياري (له قيم افتراضية)

`CYCLE_SECONDS=60` `MONITOR_SECONDS=5` `WS_ENABLE=1`
`RISK_PCT=1.0` `MAX_OPEN_TRADES=6`
`RR_MIN=2.0` `FEE_PCT=0.1` `MAX_HOLD_HOURS=48` `START_BALANCE=10000`

## 7. التجربة محلياً

```bash
pip install -r requirements.txt
cp .env.example .env   # املأ ما تريد (يعمل فارغاً بوضع التجربة)
python -m app.dry_run  # دورة واحدة حقيقية ببيانات حية
uvicorn app.main:app --port 8000  # السيرفر الكامل: http://localhost:8000
```

## 9. ملاحظات تشغيلية

- **الخطة المجانية في Render تُنام** وتوقف الدورات - استخدم `starter` (~7$/شهر) للعمل 24/7.
- أول دورة تعمل بعد ~10 ثوانٍ من الإقلاع ثم كل دقيقة.
- زر **ملخص الدورة** هو لوحة التشخيص: أي خلل في البيانات أو المحركات يظهر هناك.
- اللوحة البديلة في المتصفح: `https://خدمتك.onrender.com/` (تتحدث كل دقيقة).
- التشغيل اليدوي لدورة: `POST /cycle/run?secret=WEBHOOK_SECRET`.
